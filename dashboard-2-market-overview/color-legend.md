## Color Conventions (Dashboard 1)

| Visual | Color | Meaning |
|---|---|---|
| Median trend line, IQR line, daily observation bars | `#4A6277` (muted slate) | Neutral series color. Ordinary data, not an anomaly |
| Discount matrix, lowest value | `#F1F7F0` | Lowest discount share in the range |
| Discount matrix, highest value | `#0DB43D` | Highest discount share in the range |
| Discount matrix, zero value | `#B7D7AE` | Valid 0%: listings scraped, none discounted |
| Blank matrix cell | Default (no fill) | No listings scraped for that category and week |
